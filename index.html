設定
初期設定は一度だけ。あとはAIが自動で動きます。
Google Apps Script 接続設定
設置手順：
1. Googleスプレッドシートを新規作成
2. 拡張機能 → Apps Script を開く
3. 配布したコード（gas_backend.js）を貼り付けて保存
4. デプロイ → 新しいデプロイ → ウェブアプリ
5. 下のURLフォームにデプロイURLを貼り付けて保存
6. 「スプレッドシートを初期化」を実行
